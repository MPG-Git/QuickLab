# Desktop 1.4.0 verification — 19 November 2026

Restores useful Golden Old editor controls and menu aliases on the maintained
EEGLAB core. See [the window-by-window inventory](../../docs/GOLDEN_LAYOUT.md).
Editor file selection retains other windows and unsaved marks. Save, close,
component selection/removal, N-1 PCA and FFT export use the intended dataset.
Component scroll initialization, ERP event selection and FFT graphics workers
are corrected. Full archived experimental processing forks and filename-based
completion heuristics are not reintroduced.

Adds **QuickLab > Quick Channel Edit > REST / Infinity / Average (same
leadfield)**. Native REST and FieldTrip operate independently on identical
leadfield values. Selected EEG channels change; auxiliary channels do not.
ICA/source estimates and component rejection caches are cleared. Four synthetic
datasets, metrics and a comparison picture are supplied; **Practice data** runs
the reconstruction. The N3-specific batch script and recordings are not included.

REST 1.2 is pinned to complete official SCCN source
`ab9106d127f545f711ffb157eb0fb002a02a8552`, restoring the helper functions its
GUI calls. QuickLab MPG 1.2.0 is pinned to
`22f659666c2d10ded1c9cd3cd192881f18d06a7c` (72,979,784-byte archive;
SHA-256 `682280ccd2659498e9c1969e259cd3d90e2efcb02b2adb6fb0cf42f5548891b0`).
All 304 installed QuickLab files match that archive; non-example recordings
are excluded. Every bundled synthetic checksum matches.
