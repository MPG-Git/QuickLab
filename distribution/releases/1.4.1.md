# Desktop 1.4.1 verification — 23 November 2026

The update prompt names both installed and available versions. Checks use the
GitHub release API, then an HTTPS release descriptor outside the API rate limit,
then one API retry. Network attempts have 12-second timeouts inside a responsive
worker with a 60-second overall limit. Total failure shows **Retry / Cancel**;
it cannot masquerade as an up-to-date result. **No** defers only this launch.
Explicit rollback holds still apply. **Updates (1.4.1) > Check for updates**
checks inside MATLAB without closing the current session. Accepted in-session
updates ask the user to save, close MATLAB and reopen the desktop shortcut.

Real child-process tests reproduced Windows PowerShell losing a redirected
worker's exit code. Retaining its process handle corrects the false update
failure. During a full package test, the remote EEGLAB plugin catalog failed,
revealing a core condition that omitted five installed packages from registration.
A single guarded installer adaptation registers versioned local packages even
without that server. It preserves upstream update checks and plugin hooks.

QuickLab, NeuroLode, EEGLAB and third-party source pins are unchanged from 1.4.0.
No new upstream-version audit or scientific algorithm change is claimed.
